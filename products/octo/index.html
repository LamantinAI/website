Not a brain — the environment a brain lives in.

A distributed nervous system inspired by the octopus: many autonomous tentacles sensing and acting on the world, a core that routes events, fast reflexes, and cognition only when it is actually needed.

octo is not an agent. It owns the part that LLM SDKs, graph frameworks, and tool protocols leave to you — living in time, reacting to the world, and staying up while nobody is asking anything.

  • The envelope One fixed-shape header carrying an opaque payload. The bus routes by header fields; kinds are dot-namespaced with glob matching, so a handler can take vision.** or one exact topic.
  • Reflex before cognition A deterministic router handles the majority of events with no model in the loop, and escalates to cognition only for ambiguity.
  • Connectors are the action space A connector both senses and acts, so adding one gives the agent a new capability with zero change to cognition.
  • Sometimes no code at all A generic HTTP connector builds a whole multi-route integration from a manifest.

The shape of a turn.

Every event takes the same path, and most of them never reach a model.

the loop 
event in
  → normalize
  → reflex          // deterministic, no LLM
      ↳ escalate to cognition  // if unsure
  → action(s) out
  → memory
